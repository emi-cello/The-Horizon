# The-Horizon
A Project using Nasa APOD API to learn how APIs work

## How It Works
`1.` **Ask for Api**
> The `Sript.js` asks the api.nasa for todays image, name and description and updates `index.html` with the correct information

`2.` **Styling**
> `Style.css` fixes the text size and position to make it look preaty
